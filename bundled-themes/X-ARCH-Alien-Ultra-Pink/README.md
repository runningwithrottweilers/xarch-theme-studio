# X-ARCH-Alien-Ultra-Pink

Original SVG icon theme generated from source code. No generative AI artwork.

Includes 56 folder icon names, including `folder.svg` and `inode-directory.svg`.

## Install for testing

Copy the `X-ARCH-Alien-Ultra-Pink` directory to `~/.local/share/icons/` and select it in your desktop icon theme settings. For X-ARCH Theme Studio, use its theme import workflow if available.

The theme focuses on folder/places icons; missing icons inherit from `hicolor`. Test in an isolated environment before applying system-wide.
